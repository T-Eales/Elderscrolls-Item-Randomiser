# Tamriel Forge — Item Randomiser

A small colourful web tool for combining word lists (quality, item type, component, magic/mundane, material, etc.) into randomised MMO-style item names.

Fan-made — not affiliated with or endorsed by Bethesda Softworks or ZeniMax Media. The logo is an original emblem, not the trademarked Elder Scrolls mark.

## Usage

Open `index.html` in a browser, or visit the GitHub Pages site once enabled.

Fill each of the five slots with a comma-separated list of words for that category, then click **Randomise** to pick one word from each filled slot and combine them into an item name.

## Local development

No build step — it's plain HTML/CSS/JS. Just open `index.html`, or serve the folder with any static file server.
